# Japan adventure

# How the game works
7 * 12 = 84 levels (yay)
one level for each day of the week (yes the math is very unrealistic)
every week is a different theme of something in japan

# Game idea v1
you're a stray cat who always used to be petted by a child on their way to school. one day they dissapear, <- cutscene btw
but you discover that they've left clues for you to find them (they know youre a smart cat)
so every day non-stop for 84 days you beat every level (they get harder as you get closer to the end)
and on the end of day 84, you finally reunite with the child and the parents allow the child to adopt you.
then you die of a disease you caught on the way
